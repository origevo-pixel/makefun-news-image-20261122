THE WORLD IN ONE DAY — a one-picture front page of Sunday 22 November 2026. Five editorial panels with typeset captions cover the day's biggest stories: Iran strikes Bahrain and tankers are hit in Hormuz, Mexico captures cartel boss 'El Chapo Isidro', COP31 stalls in Antalya over fossil fuels, a drone hits a Russian cargo ship in the Baltic, and Wall Street falls into correction in an AI sell-off — plus an ALSO TODAY column with the EU–Indonesia trade deal, the Kryvyi Rih strike, the UN autonomous-weapons draft and the ATP Finals decider. The panels were generated as text-free illustrations and every word was typeset programmatically (build/compose.py), so the date and headlines stay crisp. main.ts hands the finished 1024×1024 picture in as entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
